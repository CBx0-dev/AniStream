Self-hosting the **AniStream Server Stack** allows you to run a centralized media backend on your home server, NAS, or cloud VPS.

With a self-hosted server, you get:


<Cards>
    <Card icon={<LucideRefreshCw/>} title="Centralized Synchronization">
        Watch history, bookmarks, and series progress sync across all your
        devices.
    </Card>

    <Card icon={<LucideUsers/>} title="Multi-User Profiles">
        Create separate accounts for family members or friends, each with their
        own isolated watchlist.
    </Card>

    <Card icon={<LucideRadar/>} title="24/7 Background Scraping">
        The background worker continuously keeps anime and series catalogs up
        to date, even while no one's watching.
    </Card>

    <Card icon={<LucideLayoutDashboard/>} title="Integrated Web Dashboard">
        Manage users, monitor scraper jobs.
    </Card>
</Cards>
