---
title: Upgrading
description: How updates and automatic upgrades work in AniStream Standalone.
---

AniStream Standalone includes an integrated automatic updater that ensures you always have the latest streaming scrapers, features, and bug fixes without losing your watch progress or custom watchlists.

<Callout type="warn">
    **Downgrading:** Downgrading your Data, once an update was applied to your Database is not possible.
</Callout>

## Manual Upgrades

You can also update manually at any time without losing any watch history, watchlist entries, or preferences:

<Steps>
  <Step>
    Visit the [AniStream Releases](https://github.com/cbx0/AniStream/releases) page.
  </Step>
  <Step>
    Download the latest `-standalone` installer for your operating system.
  </Step>
  <Step>
    Run the installer or replace the existing application bundle.
  </Step>
</Steps>

<Callout type="info">
  **Data Preservation**: Your local database files and settings are stored safely in your user profile directory and will remain untouched when updating AniStream.
</Callout>
