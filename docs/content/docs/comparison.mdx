AniStream offers two distinct operational modes: **Standalone** (fully self-contained local desktop application) and **Client/Server** (centralized server with lightweight desktop clients).

Both modes share the same ad-free streaming interface and provider support, but they differ in how data, watch progress, and background tasks are managed.
