# v1.0.0 - Initial Release

First release of the AniStream Client, the desktop app for the new self-hosted Client/Server mode. Instead of storing
metadata and profile data locally like the standalone app, the client connects to your own AniStream server. This
reduces local storage requirements in exchange for a minor increase in latency, and enables seamless profile and
watch history synchronization across multiple devices.

## Current features

- Connect the app to your own AniStream server by entering its URL on the first start.
- Choose your profile from the list provided by the server and sign in with your profile password.
- Watch history, watch progress, bookmarks and custom lists are stored on the server and shared across all your devices.
- Profile settings like name, avatar, theme and language are stored on the server as well.
- Browse and search the AniWorld and S.TO catalogs provided by the server, including genre filters. Outdated search
  requests are cancelled automatically while you keep typing.
- Request a sync for a series and follow its status (queued, in progress, up to date). The sync itself is performed by
  the background worker of the server.
- Same player and interface as the standalone app.
- Automatic updates: the client looks for new client releases through your server.
- Compatibility check: the server announces which client versions it accepts, and the client tells you if it is not
  compatible.
- Logging out from the preferences also forgets the saved server URL, so you can connect to a different server.
- Available in English and German.

## Requirements

- A running AniStream server. See the documentation: https://anistream.cbx0.dev/docs
- Your profile needs client access, which is configured in the dashboard of the server.
- Your server has to be reachable via HTTPS for in-app updates to work.
