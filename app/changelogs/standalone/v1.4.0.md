# v1.4.0

This release lays the groundwork for the new Client/Server mode. The standalone app keeps working fully locally with its
own database, while the project has been restructured so that the standalone app, the new client and the new server
share one codebase. Alongside that, the provider selection received a fresh look and a handful of stability issues
were fixed.

## New features

- Redesigned the provider selection screen with a clearer title, a subtitle and larger provider cards.
- The Info dialog now shows which application configuration (standalone or client) is running.
- Added a documentation website with installation and upgrade guides: https://anistream.cbx0.dev/docs

## Fixed

- Fixed the watch progress being saved incorrectly when jumping to a position via the progress bar of the video player.
- Fixed duplicate genres showing up when syncing series metadata from AniWorld and S.TO.
- Fixed the error report dialog failing recursively when the saved language or theme could not be read.
- Fixed errors caused by reusing an already closed metadata database connection.
- Improved compatibility with older WebView versions.
- Boolean values in the local database are now stored as `0` or `1` and no longer as `true` or `false`.
- Performing security audits of project dependencies and updating them
